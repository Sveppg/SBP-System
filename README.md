# SBP-System
Sound Based Prediction System for Maintenance

Sensors & Actors:
- SEN-VIB01
- SPH9645 I2S Mic
- VMA438
- ESP32-S3 1-N16R8 Dev Kit

https://www.reichelt.de/de/de/shop/produkt/entwicklungsboard_esp32-s3-wroom-1-n16r8-444792

The Project will be working with no-std bare metal rust. So if you plan on realising this project, keep in mind that
some Pins or I/O's might change and might not be working for you.
